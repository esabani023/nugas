Definisi (Satisfiable, Contradictory, Valid)

  1. Suatu kalimat tertutup (closed sentence) F adalah satisfiable jika bernilai true di bawah suatu interpretasi untuk F.
  2. Suatu kalimat tertutup F adalah contradictory (atau unsatisfiable) jika bernilai false di bawah setiap interpretasi untuk F.
  3. Suatu kalimat F dikatakan valid jika F bernilai true di bawah setiap interpretasi untuk F

Pengecekan Sifat Kalimat (Satisfiable/Contradictory/Valid)

G: (for all x)p(x) and (for some x) (not p(x))
Kalimat tersebut memiliki struktur utama berupa hubungan konjungsi (and) antara dua sub-kalimat terkuantifikasi:

  1. Conjunct 1: (for all x)p(x)
  2. Conjunct 2: (for some x) (not p(x))
Sesuai dengan aturan semantik operator and, suatu kalimat konjungsi hanya akan bernilai true di bawah suatu interpretasi I jika dan hanya jika kedua sub-kalimatnya sama-sama bernilai true di bawah interpretasi I tersebut.
Uji asumsi bahwa kalimat G bernilai true di bawah interpretasi I atas suatu domain D.
  1. (for all x)p(x) true di bawah I, menurut aturan for-all: untuk setiap d ∈ D, p(x) true di bawah <x ← d> • I.
  2. (for some x) (not p(x)) true di bawah I, menurut aturan for-some: ada suatu e ∈ D, not p(x) true di bawah <x ← e> • I, dan menurut aturan not p(x) false di bawah <x ← e> • I.
Berdasarkan pernyataan (i) dan (ii) di atas, terbukti bahwa terjadi kontradiksi antara pernyataan (i) dengan (ii), sementara kesimpulan (i) dan (ii) diperoleh dari asumsi bahwa kalimat G bernilai true atau tidak contradictory. Oleh karena itu, asumsi harus diingkar yang artinya harus diakui bahwa G merupakan kalimat yang contradictory.

Kesimpulan

Karena didapati terjadi kontradiksi pada kalimat G: (for all x)p(x) and (for some x) (not p(x)) maka asumsi bahwa kalimat G tidak contradictory adalah salah dan interpretasi I yang membuat kalimat bernilai true tersebut terbukti mustahil untuk dibuat. Oleh karena itu, haruslahh kalimat G bersifat contradictory. Jadi, kalimat G: (for all x)p(x) and (for some x) (not p(x)) merupakan kalimat contradictory.
